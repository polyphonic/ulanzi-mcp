# Setup and connection checks

1. Install MCP Server in Ulanzi Studio. Version 1.0.0 requires Studio 3.4.4 or later.
2. Drag **Server Manager** onto a button and press it to start MCP and open connection settings. Startup is manual by default.
3. Use the manager's client setup and test controls to connect your local MCP-compatible assistant. The bundled **Help** guide includes setup steps and examples.
4. Preview proposed preset changes before applying them. Keep the generated backups when replacing an existing preset.

If it does not connect, report the plugin and Studio versions, device, OS and processor, AI client and version, and the exact error shown in Server Manager. State whether the manager shows the service as running. Redact tokens, client credentials and private paths; do not upload complete client configuration files.

For manager-window or Studio-exit problems, include whether the manager was embedded or a popup, whether it was the last open popup, and whether Studio remained in the tray. Use the embedded manager while a popup issue is being investigated.

General Studio, firmware or hardware problems belong with [Ulanzi support](https://bbs.ulanzistudio.com/). Cloud-only clients need a separately configured secure connection; no AI subscription is included with this plugin.
