# MCP Server for Ulanzi

Bug reports and feature requests for Polyphonic's **MCP Server** plugin for Ulanzi Studio.
This repository contains support documentation. Plugin source and development history are private.

[Report a bug](https://github.com/polyphonic/ulanzi-mcp/issues/new?template=bug_report.yml) · [Request a feature](https://github.com/polyphonic/ulanzi-mcp/issues/new?template=feature_request.yml) · [Known issues](KNOWN_ISSUES.md)

Search existing issues before reporting. Include the exact plugin and Studio versions,
device model, operating system, steps to reproduce, and expected versus actual behavior.
Redact personal details, tokens and private paths from logs and screenshots.

See [support](SUPPORT.md) for setup checks. Unofficial community integration by
Polyphonic (Pty) Ltd; not affiliated with or endorsed by Ulanzi.
