# Known issues and verification limits

- The last-popup/tray host-exit behavior is under investigation. Use the embedded Server Manager if closing its popup also exits Studio, and report the exact steps and versions.
- Native Windows and Intel Mac acceptance remains pending. Platform support declarations are not proof that every native setup has been tested.
- Device layout validation does not replace physical-device acceptance for every supported model.

See the open issues for reports and updates. Include reproducible steps and redact personal information.
